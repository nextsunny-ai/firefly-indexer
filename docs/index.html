First-time setup

  1. Download the .dmg (macOS) or .exe (Windows), then install — drag the app into Applications (macOS) or run the installer (Windows).
  2. macOS only — security unlock (one time): the app isn't code-signed yet, so macOS blocks it. Open the Terminal app and paste this one line, then press Enter:
xattr -cr "/Applications/Firefly Indexer.app"
  1. Launch the app → click Go to Setup → press the two Run in terminal buttons (auto-installs Claude Code + signs you in). No Node.js needed.
  2. Done. On the Index page, pick a photo folder and start indexing.

Requires a Claude Pro or Max subscription. The tool runs on your own subscription — no extra cost. New to Claude Code? Fine — the two buttons handle everything.
