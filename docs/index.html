First-time setup (macOS)

  1. Double-click the downloaded .dmg → in the window, drag the Firefly Indexer app onto the Applications folder.
  2. Security unlock (one time). The app isn't code-signed yet, so macOS blocks it. Open the Terminal app (Spotlight: ⌘ + Space → type "Terminal"), paste the line below, press Enter:
xattr -cr "/Applications/Firefly Indexer.app"
  1. Open Applications (or Launchpad) → double-click Firefly Indexer to launch.
  2. A yellow bar appears at the top → click Go to Setup →.
  3. The Setup page shows two cards. In STEP 01, click the install button → Claude Code installs automatically inside the app — no terminal window. No Node.js needed.
  4. In STEP 02, click the login button → a window opens and your browser launches → sign in with your Claude account. The window closes itself once you're signed in.
  5. Top-right shows ● Ready automatically once setup is done.
  6. Click Index in the top menu → pick a photo folder → start indexing.

Requires a Claude Pro or Max subscription. The tool runs on your own subscription — no extra cost. New to Claude Code? Fine — the buttons handle everything. (Windows: just run the .exe installer, then steps 4–8.)
